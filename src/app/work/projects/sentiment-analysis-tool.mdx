## The problem

Businesses sit on piles of written feedback (tweets, reviews, survey answers) but turning it into something a manager can act on usually means a data person, a notebook and a lot of manual cleaning. I wanted a tool a non-technical stakeholder could use: **upload a CSV, get answers, download a report.** And it had to work on *any* file with a column of text, not just the dataset I tested it on.

## How it works

1. **Check the file:** counts rows, duplicates, blanks and missing values, and warns if the chosen column doesn't look like real text.
2. **Clean a copy:** tidies spaces, merges spelling variants ("late flight" vs "Late Flight"), drops blanks and duplicates, and reads dates. The original is never touched, and every change is logged with how many rows it affected.
3. **Score:** each text is scored with VADER from -1 to +1. 0.05 or more is positive, -0.05 or less is negative, anything between is neutral.
4. **Explore:** a dashboard with the overall breakdown, sentiment over time, sentiment by group (e.g. airline) and the top reasons for negative texts.
5. **Report:** tick which of 11 sections to include and download it as HTML or Markdown, along with the cleaned data and results.

## Tuning it, one change at a time

Plain VADER was too positive about complaints: it doesn't know a "cancelled" flight is bad news, and it scores "help" and "please" as positive even when someone is begging for help. I tested each fix on its own and kept only what earned its place:

## What it found in the airline data

- **Overall:** 32.7% positive, 18.3% neutral, 49.0% negative across 14,604 tweets.
- **Worst airline:** US Airways, with 60.9% negative tweets. Delta (36.2%) and Virgin America (33.3%, but only 504 tweets) were lowest.
- **Why people complained:** customer service was the single biggest reason (31.2%), though late and cancelled flights together made up slightly more (32.8%).
- **Trend:** negativity climbed from 40.3% on 18 Feb to a peak of 57.3% on 22 Feb 2015 as tweet volume doubled.

## Design decisions

- **One core, two front ends:** the Streamlit dashboard and a command-line script call the same cleaning, scoring and report code, so they always give the same numbers.
- **Guess, then confirm:** the tool guesses which columns hold the text, group, reason, labels and dates, and the user can correct any guess. That's what makes it work on any dataset.
- **Explainable over clever:** I chose a rule-based method over a trained model because it needs no training data, every score can be traced to the words in the text, and it runs on a free hosting plan.
- **Safe and repeatable:** the report is written from templates filled with the numbers, not by an AI, so the same data always gives the same report. Text is escaped so a tweet containing code can't break the page.
- **Honest about small numbers:** the report adds a caution when a group or day has too few texts to trust.

## Honest limits

VADER reads words, so it misses sarcasm and slang, and it works in English only. Even tuned, it rates fewer tweets negative (49%) than the human labels (about 63%), so it's best for **comparing** groups and days rather than stating absolute shares. And because I wrote the complaint word list after looking at this dataset, expect a smaller gain on other data. Next step: test a trained model against the 65.9% and validate on a second labelled dataset.
