# Samukelo Mngadi: Portfolio

Live site: [portfolio-team-ai-1c57.vercel.app](https://portfolio-team-ai-1c57.vercel.app/)

My portfolio as a business analyst: case studies, experience, tools and a downloadable PDF (`public/Samukelo-Mngadi-Portfolio.pdf`).

## Featured work

- **Tower**, an airline complaint triage assistant (Week 4, CAPACITI x Clickatell AI Bootcamp): [case study](https://portfolio-team-ai-1c57.vercel.app/work/tower), [code](https://github.com/mngadisamu/airline-complaint-triage)
- Sentiment analysis tool, AI business analyst assistant and #OOTD chatbot (Weeks 1 to 3)
- Systems work from my time at MICT SETA

## Built with

Next.js, React and the [Magic Portfolio](https://github.com/once-ui-system/magic-portfolio) template by Once UI, deployed on Vercel.

## Run locally

```
npm install
npm run dev
```

Content lives in `src/resources/content.tsx`, site settings in `src/resources/once-ui.config.ts` and case studies in `src/app/work/projects/*.mdx`.
